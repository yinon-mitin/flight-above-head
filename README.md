<p align="center"><strong>A light object for the room that notices when the sky changes.</strong></p>

Flight Above Head lives quietly on a shelf or wall. It can be a slow wave, a
radar sweep, an analogue clock, a field of stars, a weather portrait, or one of
fourteen ambient scenes. Then a plane crosses overhead. Or an alert arrives.
The object changes with the moment.

## It is never just one screen

**At rest**

A small, living piece of light: clocks, waves, fire, lava, geometry, stars,
weather, and scenes that move at their own pace rather than shouting for
attention.

**Above you**

A flight passing overhead takes the panel. The existing scene fades away and a
large animated aircraft opens a live card — then the room returns to calm.

**When it matters**

A regional rocket alert takes priority over everything else. At night the panel
warms and dims itself; in a dark room it falls into a near-dark sleep, while an
alert remains visible.

## Make one

The project is made for people who want to build an object, not configure a
dashboard.

```bash
git clone https://github.com/yinon-mitin/flight-above-head.git FlightAboveHead
cd FlightAboveHead
cp secrets.example.h secrets.h
cp location.example.h location.h
```

Add your Wi-Fi and location, upload the sketch, press the touch button once,
and let the panel become part of the room.

## Make it yours

Flight Above Head is an open starting point for your own ambient display, local
sky project, or living-space object. Change the scenes. Change the data. Change
the enclosure. Keep the feeling.

It is released under [Apache-2.0](LICENSE). If you redistribute it or build on
it, keep the credit in [NOTICE](NOTICE) for
[Yinon Mitin](https://github.com/yinon-mitin) and the original project.

<sub>Not a certified emergency-warning device. Keep independent official alert channels available.</sub>
